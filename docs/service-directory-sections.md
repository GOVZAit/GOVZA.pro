# Каталоги услуг

Публичная навигация внутри «Услуг»: «Специалисты» (`/`), «Врачи» (`/doctors`), «Организации» (`/organizations`). Нижняя навигация остаётся из четырёх пунктов. Запчасти остаются скрыты.

Тип профиля определяется явным `providerType`. Для старых записей без этого поля `executorType: company` означает организацию. Название бренда само по себе не превращает частного специалиста в организацию. Общая классификация применяется в каталогах, карточках, сравнении и профиле; ID и данные не переносятся и не удаляются.

Поиск и фильтры специалистов и организаций хранятся раздельно. Внутри выбранного каталога не предлагаются противоречащие ему фильтры типа профиля. Старые сохранённые фильтры нормализуются без очистки остальных условий.

«Клиники и медцентры» доступны из «Врачей» и «Организаций». Здесь отдельно показаны профили организаций с `organizationKind: medical` и места приёма, собранные из анкет врачей. Место приёма не является новым аккаунтом клиники и не получает выдуманный телефон, рейтинг, отметку проверки или идентификатор организации. Дубли адресов объединяются по названию, городу и адресу; несколько филиалов сохраняются отдельно.

Ссылка «Врачи здесь» открывает только врачей с выбранным местом приёма и показывает соответствующий адрес. Ссылка «Все врачи» снимает это ограничение. Поиск клиник использует название, город и адрес; ошибки загрузки показываются с повтором.

Проверки: отдельные проверки классификации и объединения мест приёма, адаптивные браузерные сценарии трёх каталогов, раздельный поиск и восстановление после перезагрузки, старые организации и связь места приёма с врачами. Существующие сценарии регистрации, заявки и сравнения сохраняются.
